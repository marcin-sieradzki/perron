The specs in the shipped docs data gain caller guidance agents can read: When to use, first, says when to reach for a component and which entries to use instead; each Do and don't row is a rule with an id (`DD-<n>`), a level (`must` or `should`) and what checks it (`types` or `review`); and For agents, last, holds the mistakes agents have made with it. Every component's and pattern's spec has all three, and the contract and the spec template describe them, with the measure each rule's level and check is chosen by.
