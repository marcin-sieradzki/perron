The first release. `@mylder/perron` ships Perron's foundations: the design tokens as CSS custom properties and TypeScript, the fonts, the icons, the Mylder mark, and the token and docs data the MCP server reads. `@mylder/perron-mcp` is the MCP server, with `list_tokens`, `search_docs` and `get_reference`.
