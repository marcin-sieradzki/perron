# Published as `@mylder/perron`, from npm workspaces

The name `perron` is taken on npm, so Perron publishes under the `mylder` organisation: `@mylder/perron` holds the tokens, styles, icons and components, and `@mylder/perron-mcp` the MCP server. The repository is npm workspaces from the start, `packages/perron` and `packages/mcp`, with Storybook and the docs at the root, because the MCP server was always going to be a second package. Perron is public, MIT, released from CI with Changesets and npm trusted publishing.
