Pieces of a Mylder screen, built only from Perron components

A pattern takes Mylder's own data, such as a disruption or a vehicle's trip, and lays out components for it. It never reaches past them to Base UI, so every pattern keeps their keyboard, their words in four languages and both themes.

Use a pattern

Patterns have their own entry point. Pass Mylder's data; the pattern brings the words for the kind of disruption from the reader's language.

import { DisruptionCard } from '@mylder/perron/patterns';

<DisruptionCard
  severity="delay"
  lines={[{ line: 'f', name: 'F' }]}
  title="Signal fault at Danshøj"
>
  Trains between Flintholm and Ny Ellebjerg run slower than planned.
</DisruptionCard>
