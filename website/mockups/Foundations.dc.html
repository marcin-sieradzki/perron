Using the tokens

Load perron.css once at the root. A token named color.text.primary is --perron-color-text-primary in CSS. Never copy a value.

/* app root */
import '@mylder/perron/perron.css';

.departure {
  color: var(--perron-color-text-primary);
  padding: var(--perron-space-300);
  font: var(--perron-typography-body);
}
