Button

Storybook Penpot Spec

Runs one action on the screen it sits on

Two props set its look. variant is how much it stands out: solid for the action a panel is for, outline for the actions beside it. color is the intent: neutral is ink, for every action but the main one, and brand is the bus yellow, for the one main action of a screen.
