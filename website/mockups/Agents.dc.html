@mylder/perron-mcp 0.1.1

Small, exact answers for your coding agent

The Perron MCP server answers an agent's questions about Perron's tokens, its docs and the API of the Base UI and MUI versions your project installs. The agent reads a few lines that match what is installed, instead of the sources or the hosted docs of a newer release.

Set it up

1Add it to the project's .mcp.json 
{
  "mcpServers": {
    "perron": {
      "command": "npx",
      "args": ["-y", "@mylder/perron-mcp"]
    }
  }
}
2Install Perron beside it npm install @mylder/perron The tokens and docs come from the data the installed @mylder/perron ships, so the answers always match the version you use. The server runs over stdio and needs no key.

Tools 3

list_tokens

Every token's name, CSS custom property, value in each theme, what it aliases, its reduced-motion value and what it is for. query keeps tokens whose name or description holds all its words; type keeps one DTCG type.

list_tokens({ query: "surface warning" })
TokenLightDark
color.surface.warningorange.100orange.900
color.text.warningorange.700orange.300
search_docs

The sections of the foundations, content design, the glossary and the component contract that best match query, in full. limit sets how many, three by default.

search_docs({ query: "focus ring", limit: 1 })
Accessibility › Rules Focus. Every interactive element shows the ring on :focus-visible: a focus.width solid outline in color.border.focus, focus.offset away from the element. Never remove an outline without drawing the ring another way.
get_reference

A component's API reference from the installed package's own docs. library is base-ui or mui, and part narrows it to one part. Ask it before the hosted docs.

get_reference({ library: "base-ui", component: "Select", part: "Positioner" })
@base-ui/react 1.9.0 › Select › API reference › Positioner Positions the select popup against the trigger. Renders a <div> element. side · align · sideOffset · alignOffset · collisionPadding …

Where the answers come from

node_modules/@mylder/perron/data/ Tokens and docs, for list_tokens and search_docs. Built with the release, so they never drift from it.
node_modules/@base-ui/react, @mui/material The docs bundled in each library, for get_reference. The versions your lockfile holds, not the latest release.
