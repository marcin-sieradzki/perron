# IconButton

A button that shows its action as an icon alone. Its spec has not moved over: no When to use, no For agents, and the two-column table.

## Anatomy

Filled.

## Do and don't

| Do                                              | Don't                           |
| ----------------------------------------------- | ------------------------------- |
| Give it a `label`                               | Leave it unnamed                |
| Keep it at least 24 px square (WCAG 2.2, 2.5.8) | Shrink it below the target size |
