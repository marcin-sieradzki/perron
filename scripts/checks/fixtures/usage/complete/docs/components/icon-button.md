# IconButton

A button that shows its action as an icon alone. Nothing comes close to it, and no agent has made a mistake with it yet.

## When to use

Use IconButton for an action shown as an icon alone.

Nothing else in Perron does this.

## Anatomy

Filled.

| Rule | Level  | Do                                              | Don't                           | Checked by |
| ---- | ------ | ----------------------------------------------- | ------------------------------- | ---------- |
