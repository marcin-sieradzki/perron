# Pin

A pin on the map. Its stories prove its own DD-2, which is not Flag's.

## When to use

Use Pin for a place on the map.

Nothing else in Perron does this.

## Do and don't

| Rule | Level | Do                        | Don't               | Checked by |
| ---- | ----- | ------------------------- | ------------------- | ---------- |
| DD-1 | must  | Name the place            | Leave it unnamed    | review     |
| DD-2 | must  | Give `size` a size it has | Write `size="huge"` | types      |
