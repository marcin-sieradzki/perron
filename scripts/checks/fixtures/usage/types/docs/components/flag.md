# Flag

A flag that marks one thing.

## Do and don't

| Rule | Level  | Do                        | Don't                  | Checked by |
| ---- | ------ | ------------------------- | ---------------------- | ---------- |
| DD-1 | must   | Give `tone` a tone it has | Write `tone="loud"`    | types      |
| DD-2 | must   | Give `size` a size it has | Write `size="huge"`    | types      |
| DD-3 | should | Keep the label short      | Write a sentence in it | review     |
