# StopRow

A row for one stop. Its spec has not moved over, and the WCAG rule holds of its rows all the same.

## Do and don't

| Do                     | Don't                        |
| ---------------------- | ---------------------------- |
| Name the stop          | Leave it to its icon (WCAG)  |
| Meet WCAG 2.2's 1.4.11 | Draw its edge in a pale grey |
