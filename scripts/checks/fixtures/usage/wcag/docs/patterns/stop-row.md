# StopRow

A row for one stop. Its table has two columns, and the WCAG rule holds of its rows all the same.

## When to use

Use StopRow for a stop in a list.

Nothing else in Perron does this.

## Do and don't

| Do                     | Don't                        |
| ---------------------- | ---------------------------- |
| Name the stop          | Leave it to its icon (WCAG)  |
| Meet WCAG 2.2's 1.4.11 | Draw its edge in a pale grey |
