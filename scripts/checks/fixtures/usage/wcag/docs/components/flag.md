# Flag

A flag that marks one thing.

## When to use

Use Flag to mark one thing.

Nothing else in Perron does this.

## Do and don't

| Rule | Level  | Do                                     | Don't                                       | Checked by |
| ---- | ------ | -------------------------------------- | ------------------------------------------- | ---------- |
| DD-1 | must   | Keep its words at WCAG AA contrast     | Set them in a paler grey                    | review     |
| DD-2 | must   | Keep it 24 px square (WCAG 2.2, 2.5.8) | Shrink it                                   | review     |
| DD-3 | should | Say what it marks in words             | Rely on its colour, which WCAG asks against | review     |
