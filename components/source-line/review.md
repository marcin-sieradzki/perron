NumberField Steppers also stopped this component's first build run (the pipeline's `unblocked` note), so the maintainer may want those timing-sensitive tests made robust to load.
- **P3-2.** `packages/perron/src/patterns/SourceLine/SourceLine.tsx:119` CR-1 puts a breakable space on both sides of each "·", so a wrapped line can start with the separator ("· Vehicle positions …"). A no-break space before the "·" would keep it with the word before it. This is a choice the spec made (CR-1) and the contract leaves open; it is raised as a question.
- **P3-3.** `packages/perron/src/locale/en.ts:125` The new keys `updated` and `paused` are generic dictionary names, but each is worded for the source line alone: "updated" is lower case for use inside the line. The TopBar status line the spec names ("Updated 08:14:05", paused) would need a sentence-case "Updated" under a second key. The maintainer may prefer names scoped to the source line before the keys ship.
- **P3-4.** `packages/perron/src/patterns/SourceLine/SourceLine.tsx:36` The tuple type `readonly [SourceLineSource] | readonly [SourceLineSource, SourceLineSource]` rejects a `SourceLineSource[]` built at run time, such as a second source added only when present. Data siblings take `ReadonlyArray` (VehicleTable's `vehicles`, DayProfileChart's `points`). Brief question 3 binds the tuple; this asks whether that typing cost is wanted.
- **P3-5.** `patterns-sourceline--out-of-date light, time` In both themes, each time in `typography.data` (JetBrains Mono 500) reads visibly heavier and wider than the `typography.caption` words around it (Schibsted Grotesk 400), as the build's direction note says. The Tokens table and brief question 5 set this. Since the design is deferred, it is left to a design run to confirm or to try the caption face with tabular figures.
